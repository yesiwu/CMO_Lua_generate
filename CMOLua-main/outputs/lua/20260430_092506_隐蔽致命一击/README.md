## 作战背景

红方发现蓝方补给舰（1x T-AKE + 2x DDG-84 护航）试图穿越东海。红方决定以潜艇隐蔽突击为核心，结合空中电磁压制和补充打击，摧毁蓝方高价值补给舰。

## 作战目标

| 优先级 | 目标 | 毁伤要求 |
|--------|------|---------|
| 1 | 蓝方补给舰 | >= 80% |
| 2 | 蓝方驱逐舰 1 | >= 60% |
| 2 | 蓝方驱逐舰 2 | >= 60% |

## 作战时间线

```
T+0H   [阶段一] 隐蔽接敌与目标确认
        ├─ 039C 潜艇秘密向蓝方编队预定水域机动
        ├─ J-16D + J-16-1 广域电磁侦察，精确定位
        └─ 2x 055 驱逐舰保持区域警戒

T+50M  [阶段二] 潜艇致命一击
        ├─ 039C 潜艇向蓝方补给舰齐射反舰导弹 (4x YJ-18)
        ├─ J-16D 转为电磁压制
        └─ 蓝方编队进入战斗状态

T+60M  [阶段三] 空中火力补充与评估
        ├─ J-16-2/3/4 对残存目标发起补充打击
        └─ 战果评估

T+75M  [终止]   主要目标摧毁或丧失战斗力，安全脱离
```

## 使用方法

1. 在 CMO 中打开场景后，执行 `main.lua`（创建单位）
2. 执行 `mission.lua`（加载任务规划、航线、事件）
3. 运行场景，观察作战时间线自动推进

## 文件说明

- `main.lua` — 单位部署脚本（阵营、EMCON、Doctrine、单位、参考点）
- `mission.lua` — 任务规划脚本（5个红方任务 + 2个蓝方任务 + 3个时间事件）
- `README.md` — 本文档
