# 055 vs Burke 1v1 场景说明

## 场景概述

- **红方**: 055型驱逐舰（南昌舰）
- **蓝方**: 阿利伯克级驱逐舰（DDG-51）
- **地点**: 南海

## 配置参数

| 装备 | DBID | 名称 |
|------|------|------|
| 055 | 2834 | Type 055 Renhai [101 Nanchang] |
| 伯克利 | 112 | DDG 51 Arleigh Burke |
| YJ-18 | 2867 | YJ-18 [3M54E Klub Copy] |

## 坐标

| 单位 | 纬度 | 经度 |
|------|------|------|
| 055 | 15.5°N | 115.0°E |
| 伯克利 | 15.3°N | 115.3°E |

## 作战流程

1. 创建红方/蓝方阵营
2. 红方设为全知全能（OMNI）
3. 创建055驱逐舰
4. 创建伯克利驱逐舰（autodetectable=true）
5. 清空055现有待发弹
6. 装弹16枚YJ-18
7. 发射12枚YJ-18打击伯克利
8. 自检验证

## 注意事项

- YJ-18装弹数量为16枚
- 发射数量为12枚
- 剩余4枚留在VLS中
- 蓝方单位已设置autodetectable=true，确保红方能稳定获取contact
