# 隐蔽致命一击 — 东海多域联合反舰杀伤网

## 方案概述

- **方案名称**: 隐蔽致命一击 (covert_decisive_strike_c)
- **作战时间**: 2026-04-10 12:00 开始
- **作战地域**: 东海海域
- **参演方**: 红方（攻击方） vs 蓝方（防守方）

## 作战企图

以潜艇隐蔽突击为核心，空中力量前出侦察、压制并实施补充打击，多域协同达成对蓝方护航编队的突然性与高效毁伤。

**核心目标**: 摧毁蓝方补给舰（毁伤 ≥80%），重创 2 艘护航驱逐舰（毁伤 ≥60%）。

## 使用方法

### 1. 加载 main.lua

在 CMO Lua Console 中执行 `main.lua`，完成：
- 阵营创建（红方/蓝方）
- 单位部署（8 个红方单位 + 3 个蓝方单位）
- EMCON 和 Doctrine 设置
- 参考点标注

### 2. 加载 mission.lua

继续在 CMO Lua Console 中执行 `mission.lua`，完成：
- 任务创建（M01~M07, M11~M12）
- 目标分配（打击任务关联目标）
- 航线参考点
- TCA 事件链（EV_A ~ EV_T75）
- 胜利条件事件

### 3. 运行场景

场景将按时间线自动执行各阶段作战动作。
