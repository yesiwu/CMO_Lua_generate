# Naval-Air Fire Quantity

## Quick Reference
- Match fire quantity to target priority, available inventory, and the need to retain follow-up options.
- Test quantity changes separately from target reassignment when possible.

## When To Use
- Use when the same target receives insufficient or excessive first-wave fire.
- Use when different surface targets require deliberate allocation rather than equal distribution.

## Strategy Patterns
### Priority-Weighted Allocation
- Concentrate sufficient effort against the operationally decisive target while preserving a coherent allocation for escorts and follow-up tasks.
- Record the hypothesis behind any quantity change so later outcomes can be compared.

## Counterexamples
- Do not use a larger quantity as a substitute for validating target identity and attack feasibility.
- Do not consume inventory without considering later operations.
