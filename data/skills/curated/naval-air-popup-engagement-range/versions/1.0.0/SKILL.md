# Naval-Air Pop-Up And Engagement Range

## Quick Reference
- Treat pop-up range and attack range as connected parameters with a clear exposure hypothesis.
- Preserve the requirement that attack range remains operationally coherent with the pop-up profile.

## When To Use
- Use when aircraft approach too deeply before attempting their attack.
- Use when a strike has uncertain weapon-employment opportunity or excessive defensive exposure.

## Strategy Patterns
### Range Trade-Offs
- Test whether an earlier or later pop-up changes the balance between survivability and target engagement.
- Change only the required range parameters for a focused experiment.

## Counterexamples
- Do not set inconsistent ranges that eliminate the intended approach sequence.
- Do not claim a weapon was released when direct process evidence is absent.
